# North Caspian seabed emergence

Code, data products and the full audit trail for the paper *Four decades of retreating shorelines audit projected seabed emergence in the North Caspian Sea* (working title), prepared for *Environmental Research Letters*.

**Authors:** Rezwan Ahmed (Department of Geography and Environment, University of Dhaka), Nusrat Zahan Jarin (Department of Geography, University of California, Santa Barbara; corresponding author, njarin@umail.ucsb.edu) and Obaidur Rahman (Department of Geography, Oklahoma State University).

## What the study does

The study pairs four decades of satellite waterlines with the altimetry water level of each acquisition date. That record is a natural test: at every past level, where does each global bathymetry grid put the shoreline, and where was it actually?

- **Audit (H1).** GEBCO_2026, GEBCO_2022, ETOPO 2022, ETOPO1 and SRTM15+ are flood-filled at each observed level and compared, sector by sector, with the observed shoreline and its noise floor.
- **Generality (A9).** The same audit at Great Salt Lake, with a lidar positive control.
- **Consequence (H3).** Near-term emergence 0.5–5 m below the 2026 level, with conformal intervals, exposure and the dates implied by published projection pathways.
- **Topography (H2).** A waterline elevation model of the emerged shelf, tested against ICESat-2, GLO-30 and GEDI heights.

Hypotheses, metrics and decision rules were pre-registered before any result (`docs/PREREG.md`). Every later choice is logged with its reason (`docs/DECISIONS.md`). Every number in the manuscript is generated by script from `results/metrics.json`.

## Setup and reproduction (Windows, PowerShell or Git Bash)

```bash
# 1. environment (locked): conda lock, pip-only packages, the package itself
micromamba create -y -n caspian -f requirements.lock
micromamba run -n caspian python -m pip install --no-deps -r requirements-pip.txt
micromamba run -n caspian python -m pip install --no-deps --no-build-isolation -e .

# 2. credentials (environment variables; never committed)
earthengine authenticate            # Google Earth Engine (noncommercial research registration)
setx EARTHDATA_TOKEN "<token>"      # NASA Earthdata (ICESat-2, GEDI)
setx DAHITI_API_KEY "<key>"         # DAHITI water levels
setx HYDROWEB_API_KEY "<key>"       # hydroweb.next (Hydroweb levels, SWOT)

# 3. raw inputs, under data/ (acquisition steps are never run by `make all`)
micromamba run -n caspian make fetch                 # downloads
micromamba run -n caspian make ee-inputs EE_OK=1     # Earth Engine exports (spends EECU; pilot first)

# 4. rebuild and check
micromamba run -n caspian make all        # results, figures, numbers.tex, manuscript PDFs
micromamba run -n caspian make verify-A   # Phase A checks
micromamba run -n caspian make verify-B   # paper checks
```

`make all` checks every raw input against its acquisition record (SHA-256 in `results/provenance/`) before rebuilding, and stops with the name of the acquiring target if an input is missing. `make help` lists the targets.
